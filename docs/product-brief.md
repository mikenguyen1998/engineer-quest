# Engineer Quest — Product Brief

## Purpose

Engineer Quest is a web-development practice system. It gives beginner students a guided Web Foundations course, then lets them progress to real engineering scenarios and save evidence of their thinking.

## Current release

- Passwordless Supabase accounts with cloud-saved evidence and progression.
- A six-lesson Web Foundations course plus advanced engineering tracks spanning Fresher through Expert.
- Browser-based coding exercises with live previews, progressive hints, and deterministic self-checks.
- Curated missions with a level, rubric, server-awarded XP, prerequisites, self-review, and saved evidence.
- AI-review prompt export; the user chooses their AI tool and pastes feedback manually.

## Explicit non-goals

- No public social network or leaderboard.
- No server-side arbitrary code execution.
- No automated AI-generated curriculum or automated grading claims; self-checks are instructional feedback.
- No claim that XP represents professional seniority; evidence and reflection do.

## Success criteria

After the first course, a learner can build an accessible mini-project and explain the HTML, CSS, and JavaScript choices they made. The public product also demonstrates a complete learner journey for portfolio reviewers.
